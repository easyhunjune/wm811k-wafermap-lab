# P2 E2 모델 해석

- 등록일: 2026-07-29
- 상태: 완료
- 목적: 고정된 E2 모델의 Scratch 및 Loc 판단 근거를 Grad-CAM으로 사후 진단

이 문서의 1장은 결과 산출 전에 작성한 사전 등록이며, 3장부터는 등록된 절차를
검증·테스트 분할에 적용한 뒤 작성한 결과다.

## 1. 사전 등록

### 고정 대상

- 모델: E2 `WaferCNN`
- 체크포인트: `artifacts/E2/best.pt`
- 체크포인트 SHA-256: `8743739f2402765904d9bc6e192def9f28f66bc1b8f192dfedf667fdd51a9903`
- 체크포인트 학습 seed: 42
- 체크포인트 최적 epoch: 18
- 체크포인트 최적 검증 macro F1: 0.849581857175035
- 입력: `two_channel_masks`, 2×64×64
- 대상 층: `model.features[3][0]` (`features.3.0.weight`)
- 고정 분할 SHA-256:
  `11fa5f986749f905e6b498b0a40bd4464c0575d6f73fa41215f6269b79f36090`

P2에서는 P1을 다시 실행하지 않으며 E3b 또는 E3c를 테스트 데이터에서 평가하거나
E2와 비교하지 않는다. P2 결과로 모델, 층, 하이퍼파라미터, 임계값 또는 지표를
재선택하지 않는다.

### 사례 집단

검증 분할에서 아래 네 집단으로 절차를 먼저 검증하고, 통과한 절차만 고정 E2 테스트
사례에 적용한다.

| 집단 | 조건 | 테스트 예상 사례 수 |
|---|---|---:|
| Scratch 정답 | `Scratch → Scratch` | 109 |
| Scratch 미검출 | `Scratch → none` | 89 |
| Loc 정답 | `Loc → Loc` | 410 |
| Loc 미검출 | `Loc → none` | 223 |

정량 분석에는 조건을 만족하는 모든 사례를 사용한다. 정성 그림은 집단별로
`seed=42`를 사용해 비복원 무작위로 최대 10개를 선택하며, 결과를 본 뒤 사례를
교체하지 않는다. 선택한 `source_row_id`는 `artifacts/p2/case_manifest.csv`에
기록한다.

### Grad-CAM 생성 규칙

- 모델은 평가 모드로 고정한다.
- Scratch 및 Loc 정답 사례는 실제 클래스 logit의 CAM 하나를 생성한다.
- 미검출 사례는 실제 클래스 logit의 CAM과 예측 클래스 `none` logit의 CAM을 각각
  생성한다.
- 대상 logit마다 별도 역전파를 수행한다.
- 대상 층의 채널별 gradient를 공간 평균한 값을 채널 가중치로 사용한다.
- 가중합 뒤 ReLU를 적용하고 64×64로 확대한다.
- 각 CAM은 `[0, 1]`로 정규화한다.
- 최댓값과 최솟값이 같으면 CAM을 0으로 처리하고 별도 개수를 기록한다.
- 기존 `encode_wafer_map()`의 die mask와 defect mask를 그대로 사용한다.
- 웨이퍼 밖 padding은 정량 지표에서 제외한다.

### 정량 지표

1. 결함 영역 CAM 질량 비율:
   `sum(CAM × defect_mask) / sum(CAM × die_mask)`
2. 완화된 결함 영역 CAM 질량 비율:
   defect mask를 3×3 구조 요소로 한 칸 팽창한 뒤 같은 비율을 계산한다.

분모가 0이면 결측값으로 기록한다. 실제 클래스 CAM을 기준으로 클래스별 정답과
미검출 집단의 중앙값, 1·3사분위수, 유효 표본 수, 결측 수와 0 CAM 수를 보고한다.
미검출 집단의 `none` CAM에도 같은 사례별 지표를 기록한다. 가능하면 로트 단위
부트스트랩 2,000회로 `정답 중앙값 - 미검출 중앙값`의 95% 신뢰구간을 제시한다.

### 검증 성공 기준

아래 조건을 모두 만족해야 테스트 분할로 진행한다.

- 체크포인트의 분할 해시와 현재 고정 분할 해시가 일치한다.
- 검증 저장 예측과 재추론 예측의 불일치가 0건이다.
- 네 검증 집단의 사례 수가 저장 예측에서 계산한 수와 일치한다.
- 모든 CAM의 크기가 64×64이고 유한하며 값이 `[0, 1]` 범위다.
- die mask와 defect mask가 기존 전처리 결과와 정렬된다.
- 유효 overlap 지표가 `[0, 1]` 범위다.
- hook이 실행 후 제거되고 같은 입력의 CAM이 재현된다.
- CAM이 모든 검증 사례에서 0이거나 padding에만 집중되는 현상이 없다.

검증 단계가 하나라도 실패하면 테스트 산출물을 생성하지 않고 원인을 먼저 해결한다.

### 해석 제한

Grad-CAM은 E2의 특정 logit과 관련된 공간적 활성화 단서를 보여 주지만 모델 판단의
완전한 인과 설명은 아니다. defect mask와의 중첩은 공정·장비·물리적 불량 원인을
증명하지 않는다. P2는 이미 평가가 끝난 E2의 사후 오류 진단이며 새로운 일반화 성능
검증이 아니다. `none`도 물리적으로 완전한 정상 웨이퍼라는 뜻으로 해석하지 않는다.

## 4. 고정 E2 테스트 사례 결과

### 실행 감사

테스트 분할 34,772건의 저장 예측과 재추론 예측 불일치는 0건이었다. 사전 등록한
네 집단의 사례 수도 모두 예상값과 일치했다.

| 집단 | 예상 | 관측 |
|---|---:|---:|
| Scratch 정답 | 109 | 109 |
| Scratch → none | 89 | 89 |
| Loc 정답 | 410 | 410 |
| Loc → none | 223 | 223 |

고유 사례 831개에 대해 총 1,143개 CAM을 계산했다. 미검출 사례에는 실제 클래스와
`none` CAM이 각각 하나씩 포함된다. 0 CAM, overlap 결측, 지표 범위 위반은 모두
0건이었다.

### 결함 영역 CAM 질량 비율

아래 값은 `1사분위수 / 중앙값 / 3사분위수`다. 정답 및 미검출의 `actual` 행은 실제
클래스 logit의 CAM이며, 미검출의 `none` 행은 같은 입력에서 `none` logit의 CAM이다.

| 실제 클래스 | 결과 | CAM 대상 | n | 정확한 defect mask | 3×3 팽창 mask |
|---|---|---|---:|---:|---:|
| Scratch | 정답 | actual | 109 | 0.0961 / 0.1371 / 0.1804 | 0.3254 / 0.3830 / 0.4887 |
| Scratch | → none | actual | 89 | 0.0752 / 0.1081 / 0.1510 | 0.2920 / 0.3471 / 0.4202 |
| Scratch | → none | none | 89 | 0.0575 / 0.0856 / 0.1121 | 0.2452 / 0.3180 / 0.3693 |
| Loc | 정답 | actual | 410 | 0.0759 / 0.1661 / 0.2518 | 0.2395 / 0.4216 / 0.5334 |
| Loc | → none | actual | 223 | 0.0809 / 0.1239 / 0.1750 | 0.2897 / 0.3803 / 0.4648 |
| Loc | → none | none | 223 | 0.0788 / 0.1147 / 0.1650 | 0.2865 / 0.3740 / 0.4512 |

로트 단위 부트스트랩 2,000회로 계산한 `정답 중앙값 - 미검출 중앙값`은 다음과
같다. 비교 대상은 실제 클래스 CAM이다.

| 클래스 | 지표 | 중앙값 차이 | 95% 신뢰구간 |
|---|---|---:|---:|
| Scratch | 정확한 mask | +0.0290 | [0.0071, 0.0437] |
| Scratch | 팽창 mask | +0.0359 | [-0.0073, 0.0792] |
| Loc | 정확한 mask | +0.0421 | [0.0105, 0.0759] |
| Loc | 팽창 mask | +0.0413 | [-0.0177, 0.0793] |

정확한 defect mask 지표에서는 Scratch와 Loc 모두 정답 집단의 실제 클래스 CAM
중앙값이 미검출 집단보다 높았고 로트 부트스트랩 구간도 0보다 컸다. 팽창 지표도
방향은 같지만 신뢰구간이 0을 포함하므로 경계 주변까지 허용했을 때의 차이는
불확실하다.

미검출 입력에서 `none` CAM의 defect overlap 중앙값은 실제 클래스 CAM보다
Scratch와 Loc 모두 조금 낮았다. 따라서 `none` CAM이 실제 결함 위치에 더 강하게
집중했다고 해석할 근거는 없다. 그림에서는 두 CAM의 공간 패턴이 사례별로 다르지만,
각 CAM을 따로 `[0, 1]` 정규화했으므로 서로 다른 logit의 절대 활성화 강도를
비교할 수는 없다.

## 5. 결론과 한계

고정 E2 모델은 Scratch와 Loc를 맞힌 사례에서 실제 클래스 CAM 질량을 정확한
defect mask 위에 더 많이 배치하는 경향을 보였다. 두 클래스의 `→ none` 미검출
사례에서는 이 정확한 위치 중첩이 낮았다. 이는 E2가 올바르게 분류할 때 실제 결함
다이 부근의 공간 단서를 더 잘 포착했다는 해석과 일치한다.

다만 팽창 mask 지표의 집단 차이는 불확실했고, 개별 사례의 CAM은 넓고 패딩
방향까지 퍼지는 경우가 있었다. 마지막 합성곱 특징 맵의 낮은 공간 해상도와
Grad-CAM의 근사적 성격을 고려하면 픽셀 단위 위치 설명으로 읽어서는 안 된다.
`none` 예측은 실제 클래스보다 높은 logit을 가졌다는 뜻이지만, 별도로 정규화한
CAM끼리 절대 근거의 세기를 비교할 수는 없다.

이 결과는 고정 E2의 사후 진단이다. 모델 판단의 완전한 인과 설명, 반도체 공정의
물리적 원인, 새로운 일반화 성능 또는 E3b와 E2의 테스트 우열을 뜻하지 않는다.
P1은 재실행하지 않았고 E3b·E3c를 테스트 데이터에서 평가하거나 비교하지 않았다.
